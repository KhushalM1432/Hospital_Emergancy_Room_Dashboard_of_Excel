# Hospital_Emergancy_Room_Dashboard_of_Excel
Data Science
## 📊 Dashboard Preview
* Developed an interactive **Hospital Emergency Room Dashboard in Microsoft Excel** to monitor and analyze patient volume, admission status, wait time, satisfaction scores, and operational trends.
* Performed **data cleaning, transformation, analysis, and KPI development** to convert raw emergency-room data into structured business insights.
* Implemented **PivotTables, PivotCharts, interactive filters, and dynamic visualizations** for month-wise, year-wise, demographic, and department-level analysis.
* Analyzed **patient attendance, gender distribution, age-group trends, admission rates, and department referrals** to support data-driven operational reporting.
* Designed a professional, user-friendly dashboard for **KPI monitoring, performance analysis, trend identification, and management reporting** using advanced Excel capabilities.
